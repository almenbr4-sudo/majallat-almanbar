جاريةُ الأصْمعي - قاسم العاني - سوريا - صحيفة المنبر

• 2019-01-19

مَـا لَــمْ يَــقُــلْــهُ الأصْـمَـعِــي (جاريةُ الأصْمعي) ورسَـمْــتُـهـا حـتّـى انـثَـنى من عـارضـيْـها مئْصلِـي وهُـيـمْـتُ فـي وصـْلِ الـتـنـاقشِ جـذْلـتـيِّ المـغْــزلِ حـتَّـى إذا نُـسِجـتْ ضفـيـرةُ خصْـلِها الـمُـسْـترْســلِ قــاتَ الـنـواةُ بِـكـفِّـيَ فـنَــصَــبْــتُــها كـالـمِـجْــزلِ سـاقَ الـنُـهـى من سبْـحـةٍ وروَى عُطـاشـى الـجـدْولِ بِـجَــديْــلــهــا تَـنـاغـُــمٌ لا خـــاصِــبٍ لا أفْـــلَـــلِ نــاجَـى الـمَـلاذُ بِـنَـجْـوِهـا ميْـسـا بِـظـلٍّ مُــرْفـــلِ دانَـى الـدكـوْن بِـجـذْرِها وطَـغـى سِـدافُ الـمُـسْـــدلِ جُـنَّـتْ ريْـاحُ الـصـيْـف من عـدْوٍ بِـشَـعْــرٍ مُـسْـبـــلِ وخَـشـى الحِـسـانُ نَـضَـارها تُـخْـفي بـِـدرٍّ مُـنْــجـــلِ صُـكَّـتْ صِـقَـاعُ الـقَـرْسِ عـن أهْـدَابِ جِفْـن الـعَـنْــدلِ وتَـفَـلَّـجـتْ قُـضْـبَـانُـها مِن حـاجـبٍ كالـمُـشْـمـــلِ ناحَـى البـيَـاضُ لِـحُـسْـنِـها مُـتَـيَـقِّـقَـاً منْ مـنْـهــلٍ وتَـبَـلْـسَـنَـتْ شَــدَقَـاتُـها بـعَـبـيْـر نَـفْـحِ الـمِـنْـــدَلِ وضـَّـــاءةٌ مِــن ربِّـــها بِــفُــتُــونِ وجْـــهٍ مُــنْـــــزَلِ وغَـفَـى الأمـيْـرُ بِـخَـدِّها منْ صُـوْتِ صَـفْـرِ الـبُـلْـبُــلِ شرح الألفاظ: عارضيها : صفحتا الخدين المغزل : آلة غزل النسيج والقطن المسترسل : الغير متجعد قات : أطعم - أعطى النواة : جزء مركزي .. مقصود بها هنا مركز جذر الشعر المجزل : لها معانٍ وافرة منها : الثبوت والعظمة النهى : العقل سبحة : الفراغ خاصب : كثير الخير .. المقصود بها وافر الشعر أفلل : مثلّم .. مكسّر ناجى : صوت التضرع نجوها : سرها ميساء : متبخترة مرفل : وسع الثوب وأرخاه دانى : قرب سداف : قطع السواد أو الظلام المسدل : المرخى عدْو : جرى واعتدى مسبل : مسدل منجل : ظاهر ومنكشف صكّت : دفعت العندل : الطير تفلجّت : تباعدت المشمل : السيف الصغير متيققاً : شديد البياض منهل : مصدر الشيء شدقات : جوانب الخدين المندل : العود الطيب الرائحة وضاءة : جميلة #شعر : قاسم محمد العاني
