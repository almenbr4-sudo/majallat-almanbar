مجلة المنبر — النسخة العاشرة

1. تشمل كل ملفات وأرشيف النسخة التاسعة (~4289 مقال)، بما فيها p وsocial.
2. أضيفت مشاركة فيسبوك وواتساب وإكس وتيليجرام ونسخ الرابط عبر المقالات.
3. أضيفت أولوية صورة المقال الحقيقية في واجهة المجلة ووسوم OG للمقالات التاريخية.
4. لوحة /admin/ تسمح برفع صورة من الآيفون مباشرة إلى GitHub ثم إضافة المقال إلى new-posts.json. يلزم Fine-grained PAT بصلاحية Contents: Read and write. هذا هو حاجز النشر الحقيقي؛ الرابط الإداري نفسه ظاهر للجميع. لا تضع رمزاً في ملف الموقع أبداً.
5. التعليقات: واجهتها جاهزة ولكن يلزم إنشاء موقع Disqus واختيار shortname في site-config.js. بعد ذلك تظهر التعليقات مباشرة وتدير حذفها من https://disqus.com/admin/ . لا يمكن أن تعمل التعليقات العامة دون خدمة خارجية أو خادم.
6. رفع ZIP عبر Netlify Drop قد يتداخل مع النشر الآلي من GitHub. الأفضل نشر هذه النسخة في مستودع GitHub نفسه (مثلاً Release جديد واستخدام أداة الاستيراد بعد تعديلها ليشير إلى النسخة الجديدة).
7. بعض الصور القديمة من WordPress؛ نجاح ظهورها في فيسبوك يخضع لتوفر رابط WordPress وعمل إعادة جلب المعاينة.
